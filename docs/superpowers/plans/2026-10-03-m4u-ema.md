# M4u — 가중치 평균(EMA)이 학습 한 번의 운을 줄이나 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** M4t 에서 학습 한 번이 정지차를 넘을 확률이 **약 38%** 이고, 데이터·갱신 횟수가 아니라 **배치 순서**가 그것을 정한다는 것이 나왔다. 학습 궤적 끝의 흔들림을 **가중치 지수이동평균(EMA)** 으로 누르면 성공 확률이 오르거나 배치 시드 사이 분산이 줄어드는지 잰다.

**Architecture:** `vtd_rl/policy/train.py` 에 `EmaTracker` 를 넣고 `train_epochs(..., ema=None)` 가 걸음마다 갱신하게 한다(기본 `None` 은 지금과 비트 동일). `scripts/refit_round.py` 에 `--ema-halflife H`(반복)를 넣어 EMA 그물을 `policy-ema{H}.pt` 로 따로 저장한다. EMA 는 학습 그물을 읽기만 하므로 **원래 가중치는 M4t 와 같아야 하고**, 그것이 관문이다. 원래 그물의 평가 숫자는 M4t 결과를 그대로 쓰고, EMA 그물만 새로 잰다.

**Tech Stack:** Python 3.10, PyTorch, numpy 1.26.4, pytest. 본 실행은 OMEN(RTX 3090 Ti, 32 코어, RAM 30 GB).

**Spec:** 이 문서가 스펙이다. 직전 증거는 `docs/reports/m4t-r4-drop.md`("다음" 1-(나)).

## 왜

- M4t: 같은 데이터·같은 조건에서 배치 시드만 바꾸면 ③b 가 0~31% 로 흔들린다. 그물 60 개 성공 23 개(38%), 분포가 연속이다.
- 흔들림이 **궤적 끝의 잡음**(어디서 멈췄느냐)이면 EMA 가 줄여 준다. **배치 순서마다 다른 해**로 가는 것이면 EMA 로는 안 줄고, 배치 시드를 여러 개 돌려 고르는 쪽(M4t "다음" 1-(가))이 답이다. 이 실험이 둘을 가른다.

## 실험 설계

M4t 의 A·B 조건을 EMA 를 켜고 **그대로** 다시 학습한다.

| 조건 | 데이터 | 갱신 | 배치 시드 | 원래 가중치 비교 대상 |
|---|---|---|---|---|
| A | D3(라운드 0~3) | 8 에폭 | `s+3`, `100+s`, `200+s` | `s+3`: M4s `policy-r3.pt`, 나머지: M4t `A-s{s}-b{b}/policy.pt` |
| B | D4(라운드 0~4) | 8 에폭 | `s+4`, `100+s`, `200+s` | `s+4`: M4s `policy-r4.pt`, 나머지: M4t `B-s{s}-b{b}/policy.pt` |

데이터 시드 `s ∈ {0..4}` × 배치 시드 3 × 조건 2 = **학습 30 개**, 반감기 2 개 → **EMA 그물 60 개**.

- 반감기(걸음 수): **주 지표 2500**(≈ D3 1 에폭 2,578 걸음), 보조 500. `decay = 0.5 ** (1 / 반감기)`.
- EMA 는 출발 체크포인트(M4o-s0)에서 시작한다. 학습이 2 만 걸음 넘게 돌므로 출발점의 몫은 반감기 2500 에서 0.5^8 ≈ 0.4% 다.
- 평가: 선택 창 v8~v11(③a·③b 각 72 판) + ① 원본 18 판, 평가 시드 3, **CPU**. 보고 창 v4~v7 은 안 쓴다.
- 원래 그물(raw) 숫자 = M4t `row.json`(새 배치 시드) + M4s `log.jsonl` 의 `select_eval`(원본 배치 시드). M4t 에서 둘 다 같은 절차·같은 숫자임을 확인했다.

### 판정 기준 (미리 적는다)

**성공** = 선택 창 ③b ≥ 20% (M4t 와 같다). `n_raw`, `n_ema` = 30 개 중 성공 수. 주 지표는 반감기 **2500** 이다.

1. **EMA 가 돕는다** — `n_ema ≥ n_raw + 5` **그리고** 짝(같은 학습의 raw 와 EMA) 30 쌍 중 EMA 의 ③b 가 더 높은 쌍 ≥ 18 **그리고** EMA 의 ① 평균 ≥ 90%.
2. **EMA 가 해친다** — `n_ema ≤ n_raw − 5`.
3. 둘 다 아니면 **차이 없다** — 흔들림은 궤적 끝 잡음이 아니라 배치 순서마다 다른 해다. 다음은 배치 시드 여러 개 + 선택.

보조(판정에 안 씀): 데이터 시드마다 배치 시드 셋의 ③b 표준편차 평균(raw vs EMA) — EMA 가 0.7 배 이하면 "분산이 줄었다" 고 적는다. 반감기 500 은 같은 표로 따로 적는다.

**관문:** 30 개 학습의 원래 가중치가 **전부** 비교 대상과 같아야 한다(`--compare` 의 `identical: true`). 하나라도 다르면 멈춘다 — EMA 추적이 학습을 건드렸다는 뜻이다.

```python
class EmaTracker:
    """가중치 지수이동평균(EMA) — 학습 궤적 끝의 흔들림을 평균으로 누른다(M4u).

    `train_epochs(..., ema=tracker)` 가 옵티마이저 걸음마다(`clamp_log_std` 뒤) `update(net)` 을
    부른다. 반감기는 **걸음 수**다 — `decay = 0.5 ** (1 / halflife)` 라 halflife 걸음 전 가중치의
    몫이 절반이 된다. 여러 반감기를 한 학습에서 같이 잰다.

    ★ 학습 그물을 **읽기만** 한다. 난수도 옵티마이저도 안 건드리므로, 같은 배치 시드면 학습
    그물의 가중치는 EMA 를 켜든 끄든 비트 단위로 같다 — M4t 의 재현 관문이 그대로 쓰인다.
    평균은 출발 가중치에서 시작한다.
    """

    def __init__(self, net, halflives):
        hs = list(halflives)
        if not hs:
            raise ValueError("halflives 가 비었다 — EMA 를 안 쓰려면 트래커를 안 넘기면 된다")
        for h in hs:
            if isinstance(h, bool) or not isinstance(h, int) or h <= 0:
                raise ValueError(f"halflife 는 양의 정수(걸음 수)여야 한다 — {h!r}")
        if len(set(hs)) != len(hs):
            raise ValueError(f"halflives 에 같은 값이 있다 — {hs}")
        self.decay = {h: 0.5 ** (1.0 / h) for h in hs}
        with torch.no_grad():
            self.avg = {h: {k: v.detach().clone() for k, v in net.state_dict().items()}
                        for h in hs}
        self.updates = 0

    @torch.no_grad()
    def update(self, net):
        sd = net.state_dict()
        for h, d in self.decay.items():
            for k, a in self.avg[h].items():
                if a.is_floating_point():
                    a.mul_(d).add_(sd[k], alpha=1.0 - d)
                else:                        # 정수 버퍼는 평균이 뜻이 없다 — 그대로 따라간다
                    a.copy_(sd[k])
        self.updates += 1

    def halflives(self) -> list:
        return list(self.decay)

    def averaged(self, h, like):
        """반감기 `h` 의 평균 가중치를 실은 **새** 그물 — `like` 의 설정·장치를 따른다.

        `like` 는 안 바뀐다. `load_state_dict` 가 값을 복사하므로 돌려받은 그물을 고쳐도
        트래커의 평균은 그대로다.
        """
        net = copy.deepcopy(like)
        net.load_state_dict(self.avg[h])
        net.eval()
        return net
```

```python
          ema_halflives=()):
```
