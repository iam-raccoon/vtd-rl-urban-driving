# M5c — 구성비를 유지하며 두 배로

**Goal:** M5b 에서 같은 좋은 수집자로 r1·r2 만 두 배로 늘리자 성적이 내려갔다(선택 창 70.8 → 52.0%, 갱신 수를 묶어도 62.2%). 그때 선생님만 몬 r0 의 비중이 41% 에서 25~26% 로 줄었다. **r0 도 새 시드로 같이 두 배로** 해서 구성비를 그대로 두면 회복하는지 잰다. 회복하면 데이터의 양이 아니라 **선생님 데이터와 학생 데이터의 비율**이 원인이다.

**코드 변경 없음**(`collect_episodes.py --variants --seed-offset`, `refit_round.py`, `eval_unseen.py`).

**Spec:** 이 문서. 직전 증거 `docs/reports/m5b-more-good-data.md`.

## 본 실행 (OMEN)

데이터 시드 `S ∈ {0..4}` 마다:

1. `runs/omen/2026-10-04-m5c-s{S}/data` 에 M5b 의 조각 전부(M4s r0·r1·r2 + 새 r1·r2)를 하드링크로 넣는다.
2. 새 r0: `collect_episodes.py --curriculum curricula/stage3b.json --variants 4 --round 0 --seeds 2 --seed-offset 2 --beta 1.0 --out …/data`(정책 없음 = 선생님만, 시드 2·3). r0 의 시드는 내용이 다르다(같은 판이 시드 0·1 에서 3,177·3,077 걸음).
3. `refit_round.py --upto 2 --anchor-coef 2 --near-m 30 --near-weight 3 --batch-seed {100+S} --ema-halflife 2500`(8 에폭)과, 같은 데이터로 `--max-updates`(M4y 승자의 갱신 수)를 묶은 대조를 학습한다.
4. EMA 그물을 선택 창 v8~v11·보고 창 v4~v7 로 잰다(CPU, `OMP_NUM_THREADS=1`).

## 판정 기준 (미리 적는다)

`m` = 모든 라운드를 두 배로 한 데이터 · 8 에폭 EMA 의 선택 창 ③b 평균(데이터 시드 5 개). 기준 M4s D2 = 70.8%, M5b(r1·r2 만 두 배 · 8 에폭) = 52.0%.

- `m ≥ 66.8%` → **회복한다 — 구성비가 원인**.
- `60.0% ≤ m < 66.8%` → **일부 회복한다** — 구성비가 원인의 일부.
- `m < 60.0%` → **구성비가 원인이 아니다**.

보조(판정 아님): 같은 갱신 수 대조, 보고 창 숫자. ① 평균 < 90% 면 판정과 상관없이 적는다.
