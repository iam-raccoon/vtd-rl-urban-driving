# M4p — 쉬운 단계 ③a: 처음으로 완주율이 0 이 아니다

M4o 가 단계 ③ 에서 처음으로 거리를 늘렸다(안 쓴 변종 72 판 +10~14%). 그런데 **완주율은 늘 0** 이었다 — 코스마다 액터를 4~5 개 **연속으로** 넘겨야 끝나는데 학생은 하나를 가끔 넘기는 수준이라, 그 축으로는 아무것도 못 가렸다.

그래서 **코스당 액터를 하나로 줄인 단계 ③a** 를 만들었다. **새로 학습하지 않았다** — 이미 있는 체크포인트(M3, M4o 세 시드)를 그 판에 태워 봤다.

## 단계 ③a

`curricula/stage3a.json` — 단계 ③ 에서 **각 코스의 경로상 첫 액터 하나만** 남겼다(스크립트로 뽑았다, 손으로 안 옮겼다).

| 코스 | 액터 | 종류 | 위치 |
|---|---|---|---|
| A | 301 | 정지차 `[4.5, 1.8, 1.5]` | s=560, 횡 +0.9 |
| B | 311 | 라바콘 `[0.15, 0.46, 0.61]` | s=650, 횡 −1.05 |
| D | 321 | 정지차 | s=310, 횡 +0.9 |
| E | 331 | 라바콘 | s=460, 횡 +1.05 |
| G | 341 | 정지차 | s=570, 횡 −0.9 |
| H | 351 | 라바콘 | s=200, 횡 +1.05 |

**첫 액터를 고른 이유**: 학생이 **지금 죽는 바로 그 자리**다(M4i: H 185 걸음 ≈ s200 라바콘, D 268 걸음 ≈ s310 정지차). 그래서 M4i·M4o 진단과 그대로 이어진다. 차량 3·라바콘 3 이라 관측의 두 분류 채널이 다 쓰인다. 변종 흔들기(`jitter`)도 단계 ③ 의 것을 그대로 가져왔다.

`tests/test_stage3a.py` 가 **"단계 ③ 의 엄밀한 부분집합"** 이라는 관계를 잠근다 — 깨지면 쉬운 단계 결과를 단계 ③ 와 비교할 수 없다.

### 관문 — 선생님은 전부 완주한다

| | 판 | 완주 | 완주판 점수 |
|---|---:|---:|---:|
| 원본 | 6 | **6/6** | 98.7 |
| 안 쓴 변종 v4~v7 | 24 | **24/24** | 98.7 |

## 결과 — 처음으로 완주율이 0 이 아니다

안 쓴 변종 `v4~v7`, 판 24 개 × 평가 시드 3 = **72 판**:

| | 단계 ① | **단계 ③a 완주율** | 총걸음 |
|---|---|---:|---:|
| M3 출발점 | 100% / 98.6 | **16.7%** (12/72) | 60,600 |
| M4o 시드 0 | 100% / 98.5 | **30.6%** (22/72) | 107,029 |
| M4o 시드 1 | 100% / 98.5 | **29.2%** (21/72) | 104,502 |
| M4o 시드 2 | 100% / 98.4 | **29.2%** (21/72) | 105,057 |

**M4o 가 M3 의 거의 두 배**다 — 세 시드 전부, 수집이 안 본 판에서. 단계 ① 은 그대로다.

## ★ 판별로 짝지으면 무엇을 배웠는지 보인다

M3 와 M4o 시드 0 을 같은 판(24 개)·같은 평가 시드(3 개)로:

| 판 | 액터 | M3 (/3) | M4o (/3) |
|---|---|---:|---:|
| course_B@v5 | 라바콘 | 3 | 3 |
| course_D@v4 | 정지차 | 0 | **1** |
| course_E@v4 | 라바콘 | 0 | **3** |
| course_E@v5 | 라바콘 | 0 | **3** |
| course_E@v7 | 라바콘 | 0 | **3** |
| course_H@v4 | 라바콘 | 3 | 3 |
| course_H@v5 | 라바콘 | 3 | 3 |
| course_H@v6 | 라바콘 | 3 | 3 |
| 나머지 16 판 | | 0 | 0 |

**1. M4o 는 M3 의 엄밀한 상위집합이다.** M3 가 완주한 판 4 개를 M4o 도 전부 완주하고, 4 개를 더한다. **M3 만 완주한 판은 0 개** — 퇴보가 없다.

**2. 향상은 거의 전부 라바콘에서 나온다.**

| | M3 | M4o 시드 0 |
|---|---:|---:|
| 라바콘 | 12/36 | **21/36** |
| **정지차** | **0/36** | **1/36** |

**3. M3 의 16.7% 는 실력이 아니라 위치 운이다.** M3 완주는 **전부 라바콘**이고(H v4~v6, B v5), 흔들린 횡위치 덕에 **라바콘이 학생 진로 밖에 놓인** 판이다. M3 는 액터를 한 번도 본 적이 없다(M4j: 물체 슬롯이 학습 내내 마스크였다) — 피한 게 아니라 안 부딪힌 것이다.

**4. 정지차는 둘 다 못 넘는다.** 라바콘은 폭 0.46 m 에 횡 ±1.05 m 라 **살짝 비켜도** 지나간다. 정지차는 4.5 × 1.8 m 에 횡 ±0.9 m 라 **차로를 실제로 막는다** — 진짜 차로변경이 필요하다.

## ★★ 가장 어려운 경우가 RL 여지가 있는 경우와 같다

M4h 가 찾은 선생님의 손실(단계 ③ 에서 −2.8 점)의 대부분은 **항목 ⑬ 차로변경 지시등 42 슬롯** — 장애물을 **비켜 가면서 지시등을 안 켜는 것**이었다. 그 비켜 가기가 바로 정지차를 넘는 동작이다.

즉 **학생이 아직 못 하는 것(정지차 차로변경)** 과 **선생님이 틀리는 것(그때 지시등을 안 켬)** 이 같은 자리에 있다. 학생이 정지차를 넘을 수 있게 되면 그 순간 ⑬ 이 표적으로 산다.

## 이 성적표가 주장하지 않는 것

- **새로 학습하지 않았다.** M4o 체크포인트는 **단계 ③(액터 4~5 개)** 에서 학습했고 단계 ③a 는 처음 본다. 단계 ③a 에서 학습하면 다를 수 있다.
- **판별 짝비교는 시드 0 하나**다. 시드 1·2 의 72 판 완주율(29.2%)이 같은 수준이라 방향은 같다고 보지만, 판별 상위집합 관계는 시드 0 에서만 확인했다.
- **정지차 1/36 은 신호가 아니다.** 판 하나(D@v4)·평가 시드 하나다.
- **판 24 개 중 16 개는 둘 다 0** 이다. 72 판이라도 독립적인 정보는 판 단위로 더 적다.
- 점수 열(`mean_score`)은 미완주를 0 점으로 넣어 완주율을 따라간다. 완주한 판의 주행 질은 이 표가 말하지 않는다.
- 단계 ①② 는 액터가 0 이라 "안 쓴 판" 이 없다(M4o 와 같은 한계).
