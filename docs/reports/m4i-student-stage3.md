# M4i — M3 학생은 단계 ③ 에서 한 판도 못 끝낸다

M4h 가 단계 ③(사물·정지차) 판을 만들고 선생님을 쟀다(18/18 완주, 96.8). 이 문서는 **같은 판에 M3 모방 학생을 재학습 없이 태운 결과**다. 다음 마일스톤의 DAgger 재수집 크기를 정하려는 측정이다.

    # 점수·완주율 (OMEN, 커밋된 스크립트)
    python scripts/eval_det_vs_stoch.py --checkpoint runs/omen/2026-09-26-m3-squash-warm/policy.pt \
      --stage stage1 --stage stage2 --stage stage3 --seeds 0 1 2 --stoch-seed 0 --device cpu \
      --out runs/omen/2026-09-30-m4i-student-stage3/summary.jsonl

## 실측

판 18 개(코스 6 × 시드 0·1·2), 결정적·확률적 둘 다.

| 단계 | 액터 | 결정적 완주 | 결정적 점수(완주 판만) | 확률적 완주 | 선생님(참고) |
|---|---:|---|---|---|---|
| ① 빈 경로 | 0 | **100%** (18/18) | 98.60 | 100% (18/18) | 100% / 99.6 |
| ② 신호 | 0 | **100%** (18/18) | 94.13 | 100% (18/18) | 100% / 99.5 |
| **③ 사물·정지차** | **25** | **0%** (0/18) | **—**(완주 0) | **0%** (0/18) | **100% / 96.8** |

①② 는 기존 기록(98.60 / 94.13)을 그대로 재현한다 — 측정 경로가 안 바뀌었다는 증거다.

## 실패 양상 — 전부 충돌, 전부 첫 액터에서

종료 사유를 `vtd_rl.policy.evaluate.evaluate_policy` 로 세었다(`ev["episodes"]` 의 `outcome`).

| 단계 | goal | collision | timeout | stalled |
|---|---:|---:|---:|---:|
| ① | 18 | 0 | 0 | 0 |
| ② | 18 | 0 | 0 | 0 |
| **③** | **0** | **18** | **0** | **0** |

**18 판 전부 충돌이다.** 시간초과도 정체도 없다. 걸음 수를 보면 자리까지 같다:

| 판 | 시드0 | 시드1 | 시드2 |
|---|---:|---:|---:|
| course_A | 591 | 588 | 609 |
| course_B | 824 | 679 | 680 |
| course_D | 268 | 269 | 268 |
| course_E | 385 | 384 | 385 |
| course_G | 567 | 567 | 530 |
| course_H | **185** | **185** | **185** |

**시드가 걸음 수를 거의 안 바꾼다.** 단계 ③ 의 액터는 고정이고 시드가 바꾸는 것은 신호 위상뿐이라, 학생은 **매번 그 코스의 첫 액터에서 같은 방식으로 죽는다.** 두 번째 액터까지 간 판이 하나도 없다.

**이 프로젝트에서 처음으로 `RewardConfig.collision = -50.0`(`env/reward.py:17`)과 판 종료 경로(`drive_env.py:142-143`)가 발화했다.** 단계 ①② 에서는 물체가 없어 `clr` 이 항상 99.9 라 구조적으로 불가능했다.

## ⚠ 단계 ③ 의 "점수" 를 인용하지 마라

`det_score`(raw)는 **98.13** 으로 **단계 ② 의 94.13 보다 높다.** M4d 최종 리뷰가 잡은 그 함정이다 — 채점기가 **미방문 구간을 100 점으로 채우므로 일찍 죽을수록 점수가 높다.** 학생은 코스의 5~20% 지점에서 죽으므로 나머지 구간이 만점으로 채워진다.

**완주 판만 보는 `mean_score_completed` 는 `null` 이다**(완주가 0 이라 정의되지 않는다). **단계 ③ 에서 인용할 수 있는 학생 숫자는 `0/18` 뿐이다.**

## 이것이 다음 마일스톤에 뜻하는 것

1. **보충이 아니라 재수집이다.** 100% → 0% 는 기울기가 아니라 절벽이다. 단계 ③ 에서 DAgger 를 **새로 모아야** 한다.
2. **시드를 늘려도 데이터가 안 는다.** 액터가 시드에 안 흔들리고 실패가 코스마다 한 지점에 뭉친다. **액터 위치를 무작위화하는 것이 시드를 늘리는 것보다 훨씬 많이 산다.**
3. **첫 표적은 ⑬ 지시등이 아니라 "안 박고 끝내기" 다.** M4h 는 ⑬(선생님이 비켜 가며 지시등을 안 켬, 42 슬롯)을 RL 의 표적으로 지목했다. 그 표적은 유효하지만 **순서가 뒤다** — 학생의 단계 ③ ⑬ 건수는 **0** 인데, 잘해서가 아니라 **애초에 비켜 갈 시도를 안 하기 때문**이다. 피할 줄 알게 된 뒤에야 "피하면서 지시등을 켜는가" 를 물을 수 있다.
4. **−50 충돌 항과 종료 경로가 이제 산다.** 정책이 한 번도 본 적 없는 신호이고, 단계 ③ 학습의 보상 지형은 ①② 와 질적으로 다르다.

## 이 성적표가 주장하지 않는 것

- **학생이 왜 안 피하는지는 안 밝혔다.** 관측에 물체가 들어오는데도(16 슬롯, `observation.py:135-138`) 반응을 안 하는 것인지, 관측이 실제로 안 채워지는 것인지 확인하지 않았다. **다음 마일스톤이 먼저 볼 것** — 관측이 비어 있다면 DAgger 이전에 그것부터다.
- **학생은 그 관측 채널을 학습한 적이 없다.** M3 DAgger 데이터가 전부 단계 ①② 에서 나왔고 거기엔 물체가 0 개다. 즉 물체 슬롯은 학습 내내 전부 마스크였다 — **0/18 은 놀랍지 않고, 놀라울 것이 없다는 점이 요지다.**
- **단계 ③ 의 난이도가 적정한지 모른다.** 액터 25 개(코스당 4~5)는 선생님이 완주하는 선에서 고른 값이지 학생 기준이 아니다.
- 확률적 평가도 0/18 이지만, 그것이 "잡음으로도 못 빠져나간다" 인지 "애초에 같은 자리에서 죽는다" 인지는 안 갈랐다.

## 넘기는 것

- **⚠ `scripts/summarize_dvs.py:22` 가 `STAGES = ("stage1", "stage2")` 를 박아 두고 있다.** 단계 ③ 이 든 JSONL 을 넣으면 **조용히 버린다.** 다음 비교 표를 만들기 전에 반드시 고칠 것 — 이 프로젝트가 반복해 당한 "조용한 누락" 부류다.
- 종료 사유 집계가 `eval_det_vs_stoch.py` 안에 없다(위 표는 별도 스크립트로 냈다). 성적표에 계속 쓸 숫자면 스크립트로 옮길 것.
- **slow 테스트 조각이 433 초 / 600 초 상한**이다. 단계 ④ 가 같은 종류 테스트를 더하면 넘친다.
