# M6c — 앵커 PPO 를 장애물 여럿 단계로 넓히자 ③ 전체 완주가 37.0% 에서 68.5% 로 올랐다

M6b 에서 정지차 단계로만 학습한 앵커 PPO 그물(칸 A, 계수 0.03)은, 학습에 안 쓴 ③ 전체(액터 4~5 개 코스)에서 37.0%(선택 창)였다. M6c 는 그 그물에서 출발해 학습 판에 ③a(라바콘)·③ 전체를 더하고 앵커 PPO 를 이어서 돌렸다. 코드 변경은 없다(계획 `docs/superpowers/plans/2026-10-04-m6c-ppo-stage3.md`).

## 설정

- 출발과 앵커 참조: M6b 칸 A 의 고른 그물(시드 0~2). 참조는 M4y 가 아니라 이 그물이다.
- 학습 판 30 개: ①·②·③a·③b·③ 전체의 원본 판. 200 만 걸음, 환경 10 개.
- 학습률 1e-4, 가치 워밍업 20 갱신. 칸 둘(A = 0.03, B = 0.3) × 시드 셋 = 6 실행.
- 평가는 M6b 와 같다.
  - `ac-best` 와 마지막 체크포인트를 쟀다. ①② 는 원본 판, ③a·③b·③ 전체는 선택 창 v8~v11·보고 창 v4~v7 이다.
  - 시드마다 **선택 창 ③ 전체**가 높은 쪽을 골랐다.

## 읽기

- **장애물 여럿 단계가 처음으로 과반을 넘었다.** 같은 보고 창의 ③ 전체 완주율은 다음과 같이 올랐다.
  - M4y(모방 최고, M5e) 3.3%(시드 0~2: 2.8 · 2.8 · 4.2)
  - M6b A(정지차로만 앵커 PPO) 39.4%
  - M6c A(③ 전체까지 앵커 PPO) 64.8%
- **다른 단계를 잃지 않았다.** ③a·③b 는 오히려 조금 올랐고, ①② 는 100% 다.
- **계수 0.03 이 0.3 보다 낫다.** M6b 와 같은 순서다. ③ 전체는 새 장면이 많아 더 멀리 움직여야 하는 것으로 보인다(앵커 KL A 0.12~0.32, B 0.015~0.030).
- **끝점은 아직 출렁인다.** A-s1 은 50 만 걸음 체크포인트(`ac-best`)가 70.8% 인데, 마지막은 34.7% 다. 고르기(`ac-best`)가 성적의 일부를 만든다.

- course_A 를 빼면, 실패 판의 횡 위치가 원본보다 경로 가운데 쪽이다(예: course_G 라바콘 −0.65 대 원본 −1.05). 변종이 장애물을 안쪽으로 밀어 피할 폭이 커진 판에서 부딪힌다. course_A 의 라바콘 줄은 원본과 비슷한 자리(+1.12)에서도 부딪힌다.

## 이 성적표가 주장하지 않는 것

- 칸마다 시드 셋, 200 만 걸음, 학습률 하나다. 출발점이 M6b 그물이라 M4y 부터의 두 단계 학습이다.
- `ac-best` 는 PPO 가 원본 판(시드 1, 단계마다 6 판)으로 고른 체크포인트다. 원본 판은 두 평가 창과 겹치지 않는다.
- 점수는 대회 채점기와 같은 식이지만, 이 표의 점수는 완주 못 한 판을 0 점으로 친 평균이다.
