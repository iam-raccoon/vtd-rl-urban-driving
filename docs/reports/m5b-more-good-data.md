# M5b — 좋은 수집자로 데이터를 두 배로 늘리자 오히려 내려갔다

지금 최고 그물(M4y: M4s 의 라운드 0~2 데이터 · 앵커 2 · 회피 가중 3 · EMA, 보고 창 정지차 65.8%)은 옛 손실 학생이 모은 데이터로 학습했다. M5b 는 같은 수집자(M4s 의 r0·r1 그물)로 **새 시드의 r1·r2 데이터를 같은 양만큼 더 모아** D2 를 두 배로 만들고, 같은 설정으로 다시 학습했다(계획 `docs/superpowers/plans/2026-10-04-m5b-more-good-data.md`, `scripts/collect_episodes.py --variants --seed-offset`).

- 새 r1 은 M4s `policy-r0.pt`, 새 r2 는 `policy-r1.pt` 로 모았다. β 0.5 · 걸음마다 섞기 · 같은 판(v0~v3), 시드만 1002·1003·2002·2003 이다(M4s 는 1000·1001·2000·2001). 최종 리뷰가 새 조각이 M4s 의 r1·r2 와 같은 종류임을 확인했다.
- 표본은 시드마다 약 51 만 → 80~84 만이 됐다. r0(선생님만)은 늘리지 않았다.

## 사후 대조 — 갱신이 늘어서인가

## 무엇을 뜻하나 — 양이 아니라 구성비일 수 있다

- r1·r2 만 두 배로 했으므로 **선생님만 몬 r0 의 비중이 41% 에서 25~26% 로** 줄었다(r0 21 만 / 전체 51 만 → 21 만 / 80~84 만).
- M4x 에서도 학생 라운드 데이터를 더할수록 조금씩 내려갔다(M4s D2 66.4 → D3 66.1 → D4 60.8%, a3-w4).
- 그러니 데이터의 **양**보다 **선생님 데이터와 학생 데이터의 비율**이 정지차 성적을 정할 수 있다. 이것은 가설이다.
- M4y 승자는 격자 12 칸 중 최고를 고른 것이다. 같은 설정이 데이터 구성이 바뀌면 그대로 좋으리라는 보장은 없다.

## 이 성적표가 주장하지 않는 것

- "데이터가 많으면 나쁘다" 가 아니다. **학생 라운드만** 늘렸을 때 나빠졌다.
- 구성비 가설은 아직 시험 안 했다.
- 설정은 M4y 승자(앵커 2 · 가중 3) 하나다.
